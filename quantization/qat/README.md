# 量化感知训练 (Quantization-Aware Training, QAT)

## 核心思想

QAT 在**训练过程中模拟量化效果**，让模型学会适应量化带来的精度损失。精度通常显著优于 PTQ，尤其在低位宽（INT4）场景。

## 核心问题：量化不可导

量化操作 `round()` 是阶梯函数，梯度几乎处处为零，无法直接反向传播。

```
q = round(x / scale)      ← 前向：做量化
x̂ = q * scale              ← 前向：反量化回去

∂L/∂x = ∂L/∂x̂ × ∂x̂/∂x    ← 反向：但 ∂x̂/∂x = 0（round不可导）
```

## 解决方案：Straight-Through Estimator (STE)

STE 的思想很简单：**前向时做量化，反向时假装没有量化**。

```
前向传播:  x → [量化] → q → [反量化] → x̂ → 后续计算
反向传播:  ∂L/∂x ≈ ∂L/∂x̂                 ← 直接传梯度，跳过量化
```

也就是说在反向传播时，把 `round()` 的梯度近似为 1。

## 伪量化 (Fake Quantization)

QAT 中使用的核心操作——伪量化：

```
fake_quantize(x) = dequantize(quantize(x))
                 = round(x / scale) * scale
```

伪量化节点会**插入到模型的每层权重和激活值上**：

```
原始模型:     x → Linear → ReLU → Linear → output
QAT 模型:     x → [FQ] → Linear([FQ]W) → ReLU → [FQ] → Linear([FQ]W) → output
                  ↑                                ↑
              伪量化激活值                      伪量化激活值
                            ↑                                    ↑
                       伪量化权重                            伪量化权重
```

## 训练流程

```
1. 加载预训练的 FP32 模型
2. 插入伪量化节点
3. 在训练数据上继续训练（通常只需要少量 epoch）
4. 训练完成后，将伪量化参数固化为真正的量化参数
5. 导出 INT8 模型用于推理
```

## 与 PTQ 的对比

| 对比项 | PTQ | QAT |
|--------|-----|-----|
| 需要训练 | 否 | 是（少量 epoch） |
| 需要训练数据 | 否（或少量校准数据） | 是 |
| INT8 精度 | 好 | 更好 |
| INT4 精度 | 可能较差 | 明显更好 |
| 耗时 | 分钟级 | 小时~天级 |
| 适用场景 | 快速部署 | 追求极致精度 |
