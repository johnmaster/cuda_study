# AWQ (Activation-aware Weight Quantization)

## 核心思想

AWQ 的核心观察：权重并非同等重要，**少量权重通道对激活值影响极大**。保护这些"重要"通道，就能在低位宽下保持精度。

## 关键观察

通过分析 LLM 的激活值分布发现：
- 激活值中存在明显的**异常值通道 (outlier channels)**
- 这些通道的激活值远大于其他通道（可能大 100 倍）
- 对应的权重通道如果量化误差大，会被激活值放大，严重影响输出

```
例如：某层激活值各通道的平均绝对值:
  通道 0: 0.05
  通道 1: 0.03
  通道 2: 12.7   ← 异常值通道！
  通道 3: 0.08
  ...

通道 2 对应的权重被量化后，误差会被 12.7 放大，影响极大
```

## 算法原理

### 方案一（不可行）：混合精度

简单想法：重要的 1% 通道用 FP16，其余用 INT4。但这破坏了统一的矩阵乘法，无法高效计算。

### 方案二（AWQ）：Per-Channel 缩放

对重要通道的权重做缩放，降低其量化难度：

```
原始:      Y = X @ W
缩放后:    Y = (X @ diag(1/s)) @ (diag(s) @ W)
         = X' @ W'

其中 s 是 per-channel 缩放因子
```

**关键**：s·W 让重要通道的权重值变大，量化时相对误差变小。而 X/s 让激活值变小，由于激活值本身就大，除以 s 后仍然足够。

### 缩放因子的选择

不能太大（X/s 精度降低），不能太小（W·s 提升不够）。AWQ 通过搜索最优 s：

```
对每个通道 j:
    s_j = (avg(|X[:, j]|))^α     其中 α ∈ [0, 1]

α 是通过网格搜索找到的最优指数（通常 α ≈ 0.5）
```

## 算法流程

```
1. 用校准数据前向传播，收集每层激活值统计信息
2. 对每层:
   a. 计算每个输入通道的激活值平均绝对值: a_j = mean(|X[:, j]|)
   b. 搜索最优 α，使量化误差最小
   c. 计算缩放因子: s_j = a_j^α
   d. 缩放权重: W' = diag(s) @ W
   e. 对 W' 做 Per-Group INT4 量化
3. 推理时：输入先除以 s，再做 INT4 矩阵乘
```

## 与 GPTQ 的对比

| 对比项 | GPTQ | AWQ |
|--------|------|-----|
| 核心思想 | Hessian 误差补偿 | 激活值感知的权重缩放 |
| 理论基础 | 二阶优化 (OBS/OBQ) | 激活值异常值分析 |
| 量化过程 | 逐列量化 + 逐列补偿 | 缩放权重 + 直接量化 |
| 校准数据 | 需要（计算 Hessian） | 需要（统计激活值） |
| 硬件友好性 | 好 | 更好（无需特殊反量化逻辑） |
| INT4 精度 | 很好 | 很好（略优于 GPTQ） |
| 实现复杂度 | 较高 | 较低 |

## 为什么 AWQ 硬件友好？

缩放因子 s 可以**离线融合**到权重中：
- 量化后的权重已经包含了缩放信息
- 推理时只需标准的 INT4 矩阵乘法
- 不需要额外的反量化步骤
