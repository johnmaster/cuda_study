# 非对称量化 (Asymmetric Quantization)

## 核心思想

非对称量化将浮点数的 **实际范围 [x_min, x_max]** 完整映射到整数范围 [0, 255]（UINT8），通过引入 zero_point 来处理数据不对称的情况。

## 数学公式

**量化（FP32 → UINT8）：**

```
scale = (x_max - x_min) / (2^b - 1)
zero_point = round(-x_min / scale)

q = clamp(round(x / scale) + zero_point, 0, 255)
```

**反量化（UINT8 → FP32）：**

```
x̂ = (q - zero_point) × scale
```

需要存储两个参数：**scale** 和 **zero_point**。

## 图示

```
浮点范围:  [x_min, .......... 0 ....... x_max]
                      ↕ 映射
整数范围:  [0, ........... zp ........... 255]
                         ↑ zero_point (浮点0对应的整数值)
```

## 与对称量化的对比

| 对比项 | 对称量化 | 非对称量化 |
|--------|---------|-----------|
| 整数类型 | INT8 (有符号) | UINT8 (无符号) |
| 参数 | 仅 scale | scale + zero_point |
| 零点 | 严格为 0 | 可以是任意整数 |
| 范围利用率 | 不对称数据浪费一半范围 | 完整利用 [0, 255] |
| 精度 | 对称分布数据更优 | 非对称分布数据更优 |
| 计算开销 | 更低 | 略高（需减 zero_point） |

## 适用场景

- **激活值量化**：ReLU 后激活值全为正数 [0, +max]，对称量化会浪费负半轴
- 数据分布明显偏向一侧的情况
- 需要最大化利用整数表示范围以获得更高精度
