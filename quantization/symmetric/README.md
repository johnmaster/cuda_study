# 对称量化 (Symmetric Quantization)

## 核心思想

对称量化将浮点数范围 **对称地** 映射到整数范围，浮点数 0 严格对应整数 0（即 zero_point = 0）。

## 数学公式

**量化（FP32 → INT8）：**

```
scale = max(|x|) / (2^(b-1) - 1)

q = clamp(round(x / scale), -127, 127)
```

**反量化（INT8 → FP32）：**

```
x̂ = q × scale
```

其中 `b` 为量化位宽（INT8 时 b=8），`scale` 是唯一需要存储的量化参数。

## 图示

```
浮点范围:  [-max, .............. 0 .............. +max]
                      ↕ 映射
整数范围:  [-127, .............. 0 .............. +127]
```

## 优缺点

| 优点 | 缺点 |
|------|------|
| 实现简单，只需存储 scale | 当数据分布不对称时浪费整数范围 |
| 零点严格对应，无偏移误差 | 如 [0, 10] 的数据只用到正半轴 |
| 适合权重量化（权重通常近似对称分布） | 对激活值量化可能精度不够 |

## 适用场景

- **权重量化**：神经网络权重通常呈对称分布（均值接近 0）
- 需要严格 zero-point = 0 的硬件（部分 NPU/DSP）
- 对称量化是 INT8 推理的默认选择
