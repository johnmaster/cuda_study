# 训练后量化 (Post-Training Quantization, PTQ)

## 核心思想

PTQ 在模型**训练完成后**直接进行量化，不需要重新训练。是最简单、最快速的量化方法。

## 两种模式

### 1. 动态量化 (Dynamic Quantization)

- **权重**：离线量化（提前算好 scale）
- **激活值**：推理时实时计算 scale
- 优点：无需校准数据
- 缺点：每次推理都要计算激活值的 scale，有额外开销

```
推理流程：
  输入 x → [实时计算 x 的 scale] → 量化 x → INT8 矩阵乘 → 反量化 → 输出
              ↑ 每次推理都要做
```

### 2. 静态量化 (Static Quantization)

- **权重**：离线量化
- **激活值**：用校准数据集预先统计 scale，推理时固定使用
- 优点：推理时无额外计算开销
- 缺点：需要有代表性的校准数据

```
校准阶段：
  校准数据 → FP32 模型推理 → 记录每层激活值范围 → 计算 scale/zero_point

推理阶段：
  输入 x → 量化(用校准好的参数) → INT8 矩阵乘 → 反量化 → 输出
```

## 校准方法 (Calibration)

静态量化的关键在于如何确定激活值的 scale：

| 校准方法 | 原理 | 特点 |
|---------|------|------|
| MinMax | scale = (max - min) / 255 | 简单，但受异常值影响 |
| 百分位 (Percentile) | 取 99.99% 分位点代替 max/min | 抗异常值 |
| MSE 最优 | 搜索使量化误差最小的 scale | 精度最高，计算量大 |
| KL 散度 (Entropy) | 最小化原始分布和量化分布的 KL 散度 | TensorRT 默认方法 |

## PTQ 的局限

- 对 INT8 通常效果不错
- 对 INT4 或更低位宽，精度损失可能较大
- 对量化敏感的层（如注意力的 QKV 投影）可能需要 QAT 或混合精度
